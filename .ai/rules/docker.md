# Docker (MANDATORY)

This project runs inside Docker. **Always** execute project commands inside the app container — never on the host.

- App container: `blade_app` (service in `docker-compose.yaml`), workdir `/var/www/html`.
- Prefix every command: `docker compose exec -T blade_app <command>`.

Examples:

```bash
docker compose exec -T blade_app php artisan route:list
docker compose exec -T blade_app php artisan test --compact
docker compose exec -T blade_app composer show --direct
docker compose exec -T blade_app vendor/bin/pint --format agent app routes tests database
docker compose exec -T blade_app npm run build
```

Notes:

- Container name is generated by `init.sh` (`<project>_app` / `<project>_web`), which rewrites the name in `docker-compose.yaml`, the nginx `fastcgi_pass`, `.mcp.json` **and every file under `.ai/rules/`**. So the name in this file is always the live one — if it ever disagrees with `docker-compose.yaml`, the compose file wins and `init.sh` was bypassed.
- If container is down: `docker compose up -d` first.
- Host-only exceptions: `docker`/`docker compose` itself and git.
